# Ocean 8 Aura — راهنمای سریع

## ساختار فایل‌ها

```
main.py                  ← راه‌انداز برنامه: می‌سازه، دو agent-family رو وصل می‌کنه، مسیرهای عمومی رو نگه می‌داره
agent_registry.py         ← لیست ثابت هر ۸ ایجنت (اسم + نقش) — همه‌ی فایل‌های دیگه از همینجا می‌خونن
db.py                     ← هر چیزی که به SQLite دست می‌زنه (اتصال، جدول‌ها، ثبت لاگ)
agents.py                 ← ۷ ایجنت متخصص: پرسونا + پاسخ‌دهی + مسیر /api/agents/<id>/chat
cyborg.py                 ← سایبرگ، جدا از بقیه: پرسونا + پاسخ‌دهی + مسیر /api/cyborg/chat
requirements.txt          ← لیست کتابخانه‌های لازم
templates/
    └── index.html       ← رابط کاربری سه‌بعدی (Synapse HUD)
```

**مهم:** فایل `index.html` باید حتماً داخل پوشهٔ `templates` باشد.

## چرا چند تا فایل به جای یکی؟

هر ۷ ایجنت متخصص (Ikigai, Wolf, Mercury, Saul, Scrooge, Shield, Spider) از یک آدرس مشترک
دیگه رد نمی‌شن — هرکدوم آدرس خودشو داره:

```
POST /api/agents/ikigai/chat
POST /api/agents/wolf/chat
...
```

سایبرگ کاملاً جداست: `POST /api/cyborg/chat`، با فایل و منطق خودش در `cyborg.py`.
این‌جوری بعداً که سایبرگ واقعاً بخواد با بقیه ایجنت‌ها هماهنگ بشه (نه فقط جواب بده)،
فقط همون یک فایل تغییر می‌کنه — بقیه‌ی سیستم دست‌نخورده می‌مونه.

## اجرا

```
python main.py
```

سپس پیش‌نمایش را در یک تب تازه باز کنید.

## فعال‌سازی هوش مصنوعی واقعی (اختیاری)

بدون کلید هم برنامه کامل کار می‌کند، ولی پاسخ ایجنت‌ها ثابت است.

برای پاسخ‌های واقعی:

1. از `console.anthropic.com` یک کلید API بسازید.
2. در Replit، بخش **Secrets** (آیکون قفل) را باز کنید.
3. یک مقدار جدید بسازید:
   - Key: `ANTHROPIC_API_KEY`
   - Value: کلیدی که از Anthropic گرفتید
4. برنامه را دوباره Run کنید.

## مسیرها

- `/` — رابط اصلی Synapse HUD
- `/classic` — داشبورد ساده (نسخهٔ قدیمی)
- `/api/report` — وضعیت زندهٔ همه‌ی ایجنت‌ها با یک درخواست (JSON)
- `/api/agents/<id>/chat` — ارسال پیام به یکی از ۷ ایجنت متخصص
- `/api/cyborg/chat` — ارسال پیام به سایبرگ

## نکته دربارهٔ دیتابیس

برنامه دیتابیس خودش را با نام `ocean8_aura.db` می‌سازد و به فایل‌های
قبلی شما دست نمی‌زند. اگر از قبل این دیتابیس را داشته باشید، ستون‌های
جدید به‌صورت خودکار و بدون حذف اطلاعات قبلی اضافه می‌شوند.
